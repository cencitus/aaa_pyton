Программа читает файл Corp_Summary.csv с данными сотрудников: ФИО, департамент, команда, должность, оценка, оклад.
По выбранному номеру формируется один из трех отчетов:
1) Иерархия: для каждого департамента показываются входящие в него команды.
2) Сводка по департаментам: название департамента, количество сотрудников, минимальная, максимальная и средняя зарплата.
3) CSV-отчет: та же сводка, что во втором варианте, но записанная в файл report.csv.

Запуск
Файл Corp_Summary.csv должен находиться в той же папке, рядом с main.py
Из папки с файлом выполнить
```python main.py```

После запуска нужно выбрать номер отчета от 1 до 3. Для выхода ввести 0.
Для работы используется только стандартная библиотека Python.
