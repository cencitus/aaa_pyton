# Домашнее задание №1

В папке homework_1 находятся пять заданий.

## Требования
Python 3.
Все задания используют стандартную библиотеку Python. Установка дополнительных зависимостей для запуска не требуется.

## Запуск
Открыть терминал в корневой папке репозитория.
Для запуска первого задания:
```bash
python homework_1/1.1.py
```
Остальные задания запускаются аналогично, с указанием соответствующего имени файла.
