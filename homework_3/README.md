# Домашнее задание 3

Программа анализирует данные о лауреатах Нобелевской премии из файла laureates.json.

Сначала данные обрабатываются с помощью конфигов и преобразуются в более удобный формат. Затем проводится анализ:

1. Количество лауреатов, пропуски в данных и проверка ID.
2. Возраст лауреатов при получении первой премии по категориям и десятилетиям.
3. Гендерное распределение лауреатов по категориям и десятилетиям.
4. Количество награждений, статусы премий и топ-5 категорий.
5. Анализ текстов мотиваций вручения премий: топ-50 частых слов, удаление стоп-слов и сравнение топ-10 слов по категориям.

Вспомогательные функции для обработки данных и расчета статистик вынесены в отдельные .py-файлы.

## Запуск

Файл laureates.json должен находиться в папке `homework_3`, рядом с ноутбуком и остальными файлами Python.

Из этой папки нужно открыть laureates_countries_task.ipynb в Jupyter Notebook или VS Code и выполнить все ячейки по порядку.

Для обработки данных используется стандартная библиотека Python. Для запуска ноутбука необходим Jupyter.
